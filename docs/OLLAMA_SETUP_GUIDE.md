# How to Run Local LLMs for Free (Ollama Guide)

> **Source**: Shared guide for running free, private, offline models on Mac/PC.
> **Requirements**: 8GB+ RAM (works on any Mac or PC).

## 1. Install a Runtime
- **Ollama** (CLI + local API) – [ollama.com](https://ollama.com)
- **LM Studio** (GUI) – [lmstudio.ai](https://lmstudio.ai)

## 2. Download & Run a Model
```bash
ollama pull qwen3-coder
ollama run <model-name>
